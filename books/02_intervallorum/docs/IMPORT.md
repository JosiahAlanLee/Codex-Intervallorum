# GitHub import record

Repository: https://github.com/JosiahAlanLee/Clavicula_Intervallorum

The current source tree was uploaded through the GitHub API because authenticated
Git transport was unavailable in the working environment. The GitHub import has
its own commits; it does not claim the original repository ancestry as its own
parent chain.

`HISTORY.bundle` preserves the original upstream history and the prepared
Clavicula Intervallorum edition through commit
`d6a13b6b94103410da5a1ef808395584136be755`. It was verified with
`git bundle verify` before upload. To restore that history locally:

```bash
git clone HISTORY.bundle my-grimoire
```

The bundle does not recursively contain itself. The source tree's later import
notes are ordinary additions to the GitHub edition. The book, diagrams, and
portable build are the validated edition already provided for review.
