# Incident exercises: methods and reported findings

Public research record, 18 October 2026. This note summarizes two project reports read in full. Their source excerpts are supplied here; their companion case ledgers, code, prompt files and judging materials are not. The reports' descriptions of those materials are retained as descriptions, not represented as runnable contents of this repository.

This note does not independently reconstruct the source incidents or reproduce the incident-analysis code. The gate-and-window runner elsewhere in the repository is a different simulation. Its A/B/C labels are not the incident study's proposed review conditions.

## Original exercise: 10 October 2026

The [report excerpt, pp. 1–6 of 7](reports/2026-10-10-pilot-excerpt.txt), describes six incidents from five organisations. The selected operator reports concern AWS 2017, GitLab 2017, Cloudflare 2019, GitHub 2018, Facebook 2021 and Cloudflare 2023. Organisation and source dependencies therefore remain visible.

One analyst produced source-located codes, a competent SRE interpretation and a protocol interpretation with outcomes visible. There were no independent model runs, independent judges or fitted causal comparisons. Prior familiarity with well-known incidents was acknowledged. A locally frozen design was not external preregistration.

The reported exercise found overlapping operational readings and substantive evidence gaps. It supplied no independently established protocol-only discovery. None of the six empirical bets received a comparative effect estimate. Eighteen development prompts for the independent three-condition experiment were explicitly unrun.

The proposed comparison was competent review alone, competent review plus the protocol, and competent review plus a generic addition of similar length. Equal length would still not by itself establish equal effort, effective blinding or representative sampling. Those remain design questions for an executed study.

## Expanded exercise: 11 October 2026

The [report excerpt, pp. 1–4 of 6](reports/2026-10-11-pilot-excerpt.txt), describes ten units. Its main denominator is eight new, non-originating units. Cloudflare repeats from the first exercise, the Hugging Face incident informed the original concept, and Anthropic's related incidents are treated as one source cluster. The sample is purposive and retrospective.

The report describes ten paired manual readings, nine timestamp calculations and sensitivity counts. The same analyst knew the outcomes. Aggregation of annotations was reported as reproducible, but the independent three-condition comparison and independent judging were again not executed.

For the eight new units, the analyst coded source availability as follows. These are reported annotations, not independently validated frequencies of institutional properties:

| Evidence available in the selected sources | Reported units |
| --- | --- |
| Timed response sequence | 6/8 |
| Specific obstruction to correction, execution or investigation | 6/8 |
| External authority actually exercised | 3/8 |
| Implemented post-incident change explicitly reported | 3/8 |
| Post-incident behavioural perturbation experiment | 1/8 |
| Metric gaming meeting the original narrow code | 0 documented; 8 unknown |
| Actual reporter-protection or retaliation regime | 0 documented; 8 unknown |
| Usable ownership comparison | 0 available |
| Recurrence follow-up with exposure and ascertainment | 0 available |

The first five fields were not measured in the initial exercise, so this is not a before/after efficacy comparison. Different time endpoints also cannot be pooled into one restoration score or assigned wholesale to blocked permission. Decision, attempted execution, effective action and safety/integrity checks can diverge.

All five distinctive comparative proposals remained untested by an adequate design. Two partial displacement codings concerned different actors and endpoints; they establish neither a complete metric nor a comparative recovery benefit.

## Permitted interpretation

Both exercises demonstrate the application of a vocabulary at the level of one retrospective analyst and expose missing evidence. Neither estimates the added value of the protocol over competent equal-length review. Neither supplies a measured null effect, equivalence result, inter-reader reliability estimate or causal ownership comparison.

An unknown reporting regime is not evidence that reporting was protected or punished. A technically separate recovery path does not establish independent ownership. A changed configuration is not automatically a revision of institutional goals. These are limits the reports themselves identify.

The excerpts preserve original page labels and omit the source-register pages. They are project evidence about what work was reported, not a substitute for the original public incident sources or independent examination of the unavailable companion materials.
